GENERIC COMPATIBILITY SPECIFICATION v2.0
PHASE 1 - CHARACTER NORMALISATION
==============================================

Purpose
-------
Phase 1 normalises non-ASCII characters observed in the six-model corpus of 300 pseudocode algorithms before generic lexing. These rules apply only to GENERIC_COMPATIBILITY. GENERAL_NO_CONVERSION remains unchanged. AJ_DIALECT_STRICT retains its existing safe-cleanup behaviour.

-----

GC002  ≤       -> <=          Unicode less-than-or-equal operator

GC010  ‘       -> '           Opening smart single quote
GC011  ’       -> '           Closing smart single quote
GC012  –       -> -           Unicode en dash
GC013  U+2005  -> SPACE       Four-per-em space
GC014  U+00A0  -> SPACE       Non-breaking space
GC015  U+200B  -> REMOVE      Zero-width space
GC016  U+FEFF  -> REMOVE      UTF-8 BOM / zero-width no-break space
GC017  n°      -> n DEG       Degree suffix when immediately preceded by a digit
