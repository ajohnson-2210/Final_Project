The only approved rewrite is:

```text
RETURN CALL unique(result)
```

to:

```text
RETURN result
```

It refuses alias/call escape, direct or indexed rebinding, `INSERT`, unguarded/mismatched appends, repeated appends under one proving guard, and loops nested beneath the proving guard.

This preserves the ordering generated by the source and does not implement a general `unique` helper.
