NL-FDEP Final Scoring Dashboard

This dashboard brings together the automated study outputs and the completed Human Review evidence. It calculates a model-level automated overall score from the two automated measures. A Human Review Overall and Combined Final Score are only reported after all __ALGORITHM_COUNT__ algorithm reviews for that AI agent reach a terminal Human Review outcome. Completed non-scorable outcomes explicitly contribute 0% under the failure-to-demonstrate rule described below.

Human Review Overall — eligibility and missing-data rule

Unit of analysis: one planned algorithm instance. Each AI agent has N = __ALGORITHM_COUNT__ algorithm reviews in this study, and the Human Review Overall retains that fixed denominator N.

  • Observed-score rule: a completed review with a numerical Human Rubric percentage contributes its observed percentage.
  • Completed non-scorable exception: when adjudication explicitly records HUMAN_REVIEW_COMPLETE_NOT_EVALUABLE (for example, all applicable rubric entries are explicitly NA), the review is a terminal completed non-scorable outcome. It remains in N and contributes 0%. This is labelled a failure-to-demonstrate rule, not statistical missing-value imputation.
  • Incomplete or technically unresolved records: partial, empty and pending reviews are never assigned zero. Likewise, a completed record with no numerical percentage but without the explicit terminal non-evaluable adjudication status is treated as a technical/data-quality exception. Human Review Overall remains withheld until it is resolved.
  • Eligibility threshold: the metric becomes eligible only when all N planned algorithms are complete and each has either a numerical Human Rubric percentage or an explicit completed-non-scorable terminal outcome. For this study that is __ALGORITHM_COUNT__/__ALGORITHM_COUNT__ terminal outcomes.
  • Descriptive audit statistic: the numerical-only completed-review mean is shown separately. It deliberately excludes zero-credit non-scorable cases so the effect of the fixed-denominator rule is visible rather than hidden.
  • Cross-agent final ranking: Combined Final is used for ranking only when every AI agent has an eligible Human Review Overall. Until then, all agents are ranked on Automated Overall only and the ranking is labelled provisional.

Methodological precedent (analogy, not an identical rubric): fixed-denominator code-generation benchmarks such as HumanEval (Chen et al., 2021) and SWE-bench (Jimenez et al., 2023) evaluate a predefined set of problem instances and report success over that fixed instance set rather than dropping unsuccessful attempts from the denominator. NL-FDEP applies that benchmark principle only to an explicitly terminal human-review outcome: failure to produce assessable rubric evidence receives zero credit, while genuine missing/technical data do not.

References: Chen, M. et al. (2021), Evaluating Large Language Models Trained on Code, arXiv:2107.03374. Jimenez, C. E. et al. (2023), SWE-bench: Can Language Models Resolve Real-World GitHub Issues?, arXiv:2310.06770.

Comparative scoring overview — full-width axis-swapped view

The full-width axis-swapped chart places score percentage on the horizontal x-axis and AI agents on the vertical y-axis. On tablets and phones, the chart retains a constant 820 px height while its width automatically fits the available panel, with no horizontal overflow. It shows five values for each agent: mean semantic behavioural score, aggregate Common Test accuracy, automated overall score, human review overall score, and combined final score. Human Review Overall and Combined Final remain blank until that agent has N/N terminal Human Review outcomes. Completed non-scorable outcomes contribute an explicit 0%; incomplete or technically unresolved values are never imputed.

Cross-agent scoring and ranking table

A final cross-agent ranking is produced only when every AI agent has an eligible N/N terminal Human Review set. Before that point, the displayed order is an automated-only provisional ranking for all agents; the dashboard never mixes final combined scores and automated-only scores in the same ranking.
